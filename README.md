<h1>Небольшая конфигурация для проектов без использования библиотек</h1>

Данная конфигурация предназначена для проектов, не использующих внешние библиотеки. Она обеспечивает возможность подключения и настройки полей для доступа к базе данных и других необходимых параметров без изменения программного кода. Все настройки осуществляются через файл конфигурации "settings.ini".

<h3>Инструкция по установке и использованию:</h3>

1. Загрузите и разместите папку "config" в корневой директории вашего веб-приложения или в любом другом удобном для вас месте.
2. Включите данную конфигурацию в ваш основной исполняемый файл (например, через загрузчик):

<code>require_once __DIR__ . '/config/bootstrap.php';</code>
(укажите ваш путь вместо /config/bootstrap.php)

<h3>Описание доступных параметров:</h3>

* <b>TODAY</b> — текущая дата в формате <i>Y-m-d</i>.
* <b>TIME</b> — текущее время в формате <i>H:i:s</i>.
* <b>TODAY_TIME</b> — комбинированное значение даты и времени в формате <i>Y-m-d H:i:s</i>.
* <b>IP</b> — IP-адрес устройства, осуществляющего подключение.
* <b>SECURE</b> — логическое значение, указывающее на тип соединения <i>(true для HTTPS, false для HTTP)</i>.
* <b>ADMIN_KEY</b> — ключ администратора.
* <b>ROOT_URL</b> — корневой URL-адрес вашего веб-сайта.
* <b>DB_HOST_NAME</b> — имя текущего хоста используемой базы данных.
* <b>DB_NAME</b> — название текущей базы данных.
